# TG Account Rescue

Мини-приложение для Telegram, которое помогает вернуть доступ к аккаунту через **официальные каналы поддержки Telegram** — без запроса или хранения чужих учётных данных.

🔗 Живая версия: https://db5000-ux.github.io/recovery-tg/

## Что умеет сейчас

- **Восстановление** — пошаговая подготовка обращения в поддержку Telegram: проверка 2FA, свободное описание ситуации, автогенерация текста письма, прямые кликабельные ссылки на официальные каналы (форма поддержки, recover@telegram.org).
- **Чек-лист защиты** — 5 настроек, которые закрывают самые частые способы угона аккаунта, с прогресс-баром и подробными пошаговыми гайдами (Android / iOS / Web) по каждому пункту.
- **Голосование за название** — сообщество само выбирает имя проекта (варианты и голоса общие для всех, кто открывает приложение).
- **Отзывы** — любой пользователь может оставить отзыв и оценку.
- 👍/👎 на разделах «Мониторинг сессий» и «Экстренный режим» — чтобы понимать, насколько они нужны, прежде чем их разрабатывать.
- Двуязычный интерфейс (RU/EN) с автоопределением языка.

## В разработке

- **Мониторинг сессий** — уведомления о новых входах и завершение чужих сессий в реальном времени.
- **Экстренный режим** — кнопка «Меня взламывают»: массовый разлогин, смена пароля и email одним действием.

Оба модуля предполагают работу с сессией пользователя Telegram (через MTProto/официальные библиотеки вроде Telethon или GramJS) и сознательно отложены до тщательной проработки безопасности — приложение не должно само стать точкой риска для тех, кто им пользуется.

## Облачное хранилище (голосование, отзывы, лайки)

Эти функции завязаны на **Firebase Realtime Database** через её обычный REST-интерфейс (без SDK и сборки). 

## Запуск в Telegram

1. Файл — статический, хостится на GitHub Pages по HTTPS.
2. Бот создаётся через @BotFather; ссылка на приложение привязывается через Menu Button (`/mybots` → Bot Settings → Menu Button) или через `/newapp` для прямой ссылки `t.me/<bot>/<shortname>` — она открывает приложение сразу, без поиска кнопки меню.
3. Кнопка **Start** у бота ничего не делает — это ожидаемо, у бота нет серверной логики для ответа на `/start`. Открывать приложение нужно через кнопку меню или прямую `t.me/…` ссылку.
4. В `<head>` подключён официальный `telegram-web-app.js` — через него работают шаринг внутри Telegram и кнопка Stars.

## Приватность

Приложение не запрашивает и не хранит доступ к аккаунту Telegram пользователя. Текст обращения в поддержку формируется локально в браузере и никуда не отправляется, пока пользователь сам не скопирует его.
